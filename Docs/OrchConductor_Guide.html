OrchConductor

The one global CC hub in the built system — everything downstream of it is generic, source-agnostic, per-track.
control path · CC 20-62, ch 1 live Ocnd

A full-score orchestration sender: combi presets, per-section presets, a Narrative Scan mode that walks a named arc shape across up to 64 combi "stops," an Instrument Combi Grid for hand-tuning any combination, and a response bridge that broadcasts a deterministic articulation randomizer to every OrchGate in the rig. The biggest, most feature-dense plugin in the family — this guide uses one marker per region, not per control, with full tables carrying the exhaustive detail.

Only the default Conductor view is screenshotted below. Combi Grid (43 instrument sliders) and Narrative Lane (the arc-proposal editor) are documented from source in §02–§03, same depth, no picture — switching views needs a live click this session couldn't automate on an unlisted build.

2
Combi Preset & Authority Mode
combiPreset · authorityMode
Authority Mode picks which of 3 sources actually drives the CC20-62 output: Manual Sections (the 4 dropdowns in region 4), Combi Preset (one named preset for the whole orchestra), or Narrative Scan (region 6).
3
User Combi Management
Name + Save Current Sections as Combi captures whatever's currently sounding (manual dropdowns + Harp/Piano sliders) into a new named combi. Delete/Export/Import round-trip the whole user library as JSON.
4
Manual Section Presets
woodwindsPreset · brassPreset · percussionPreset · stringsPreset
Only drive output while Authority Mode = Manual Sections. Each section has its own named preset list.
5
Harp / Piano (manual)
UI-only session state, not host-automatable APVTS params (manualHarpValue / manualPianoValue, plain members, -1 = off) — CC49/CC55 direct control in Manual Sections mode. Precedence: manual sliders > narrative lane point > user combi's own harpValue/pianoValue.
6
Narrative Scan
narrativeLane · narrativePosition
Walks the selected lane's combi "stops" by position (0..1) with hysteresis, resolved via the same 6+ CC102/103 bridge MC drives (see the Signal Map). Export/Import Lane Library JSON grows the lane set without a rebuild — this rig's own library currently holds 9 lanes.
7
Gate Response Bridge
gateResponseModeCc · gateResponseAmountCc
Broadcast Gate Response + Shuffle + Amount/Mode sliders — the live manual panel for the CC106/107 bridge that drives every OrchGate's own per-instance-seeded articulation randomizer. Panel overrides whatever the active narrative lane point requests while enabled.
8
Status Bar
Build/authority/catalog line plus a live send readout — active players, harp/piano values, last action, send-request count. The fastest way to confirm what's actually being sent without a MIDI monitor.
Real capture of the Standalone build, Phase 10G, Authority Mode = Manual Sections, runtime JSON catalog active.

Each proposed stop also carries an optional pitch-field index (drives OrchNoteFilter's harmonic field via CC105), Harp/Piano override, and Gate Response mode/amount — one Narrative Position automation lane can drive orchestration, density, harmonic field, and articulation together. Save to Lane Library / Load / Delete round-trip against the same JSON file §01.6's Export/Import buttons use.
